# NLP Sentiment Analysis using ANN

##  Project Overview

Developed an **NLP-based sentiment analysis model** to classify movie reviews based on their sentiment. The project combines text preprocessing, TF-IDF feature extraction, and an Artificial Neural Network (ANN) to perform binary sentiment classification.

##  Objective

* Analyze and preprocess movie review text.
* Convert text into numerical features using TF-IDF.
* Build an ANN model for sentiment classification.
* Evaluate model performance using classification metrics.
* Visualize model performance and sentiment distribution.

##  Key Steps

* Loaded and explored the movie review dataset.
* Handled missing values and duplicate records.
* Performed text preprocessing:

  * Lowercasing
  * Tokenization
  * Stopword removal
  * Lemmatization
* Converted cleaned text into numerical features using **TF-IDF**.
* Split the data into training and testing sets.
* Built and trained an ANN model.
* Generated sentiment predictions.
* Evaluated the model using Accuracy, Precision, Recall, F1-Score, and Confusion Matrix.
* Visualized accuracy, loss, confusion matrix, and sentiment distribution.

##  Model

* Built an ANN using **TensorFlow/Keras Sequential API**.
* Hidden Layer 1: **128 neurons with ReLU activation**.
* Hidden Layer 2: **64 neurons with ReLU activation**.
* Dropout: **50%** to reduce overfitting.
* Output Layer: **1 neuron with Sigmoid activation**.
* Loss Function: **Binary Cross-Entropy**.
* Optimizer: **Adam**.
* Training: **10 epochs**.

##  Result

* Successfully classified movie reviews into sentiment categories.
* Generated predictions on the test dataset.
* Evaluated performance using Accuracy, Precision, Recall, F1-Score, and Confusion Matrix.
* Visualized training accuracy and loss to analyze model performance.
* Compared actual and predicted sentiments to identify correct and incorrect predictions.
